# . (dot) vibes — GitHub Pages + Firebase

1. Create a Firebase Web App in project `vibes-699f5`.
2. Copy its Web configuration into `firebase-config.js`.
3. In Firebase Authentication enable Anonymous sign-in.
4. Create Firestore Database.
5. Upload these files to a GitHub repository.
6. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
7. Open the GitHub Pages URL.

This is a website/frontend starter. Real live audio, paid coins/gifts, and production security require additional backend/RTC work.
